🐙 GitHub Setup Guide
Deploy your dashboard and EA from your phone
  1. 1
    Install GitHub Mobile
    Download the GitHub app on your phone. Sign in or create a free account at github.com
  2. 2
    Create a new repository
    Tap + → New Repository → Name it trendrsi-dashboard → Set to Public → Create
  3. 3
    Upload your files
    In the repo, tap Add file → Upload files → Select index.html and TrendRSI_EA.mq5 → Commit changes
  4. 4
    Deploy to Vercel (free)
    Go to vercel.com → Import Git Repository → Select your repo → Deploy. You'll get a live URL like: https://trendrsi-dashboard.vercel.app
  5. 5
    Add the API route
    Create file api/signal.js in your repo: export default function handler(req, res) { if (req.method !== 'POST') return res.status(405).end(); // Store signal, push to clients console.log('Signal:', req.body); res.status(200).json({ ok: true }); }
  6. 6
    Update MT5 EA WebhookURL
    Paste your Vercel URL into the EA's WebhookURL input parameter. Enable WebRequest for this URL in MT5 Options.
  7. 7
    Done! 🎉
    Your EA now sends live signals to your dashboard. Open the site on your phone to monitor trades anywhere.
